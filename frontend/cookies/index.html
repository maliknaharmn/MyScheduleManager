Kembali ke aplikasi

Penyimpanan tema dan cache agenda tidak aktif sebelum kamu mengizinkannya. Menolak keduanya tidak menghalangi login atau menghapus data akunmu.

Cookie wajib

  • myschedule_session: pengenal sesi login, bukan kata sandi atau token akses Google. Umur default hingga 7 hari; dapat berakhir lebih cepat setelah keluar atau pencabutan sesi. HttpOnly, Secure di produksi dan SameSite=Lax.
  • myschedule_oauth: mengikat percobaan login ke browser untuk keamanan OAuth. Umur hingga 10 menit dan dibersihkan setelah alur login selesai.
  • myschedule_storage: mengingat pilihan kategori penyimpanan browser selama 180 hari, atau sampai diubah/dihapus. Memuat versi pilihan, dua nilai izin opsional dan waktu kedaluwarsa, bukan isi agenda atau identitas Google.

Cookie ini dibutuhkan agar autentikasi, keamanan dan penghormatan terhadap pilihanmu bekerja. Menonaktifkannya melalui browser dapat membuat login gagal atau pilihan perlu diulang. Cookie pilihan tidak digunakan untuk iklan.

Penyimpanan opsional

  • Preferensi tema: cookie myschedule_theme mengingat mode terang/gelap selama 30 hari. Sebelum izin diberikan, perubahan tema hanya ada di memori halaman.
  • Cache agenda: IndexedDB myschedule-week-cache-v1 menyimpan salinan agenda mingguan menurut akun, termasuk judul, waktu dan status yang ditampilkan. Cache lebih tua dari 30 hari tidak dipakai dan dibersihkan saat penulisan cache berikutnya. Jika situs tidak dibuka, browser dapat tetap menyimpan salinan lama sampai dibersihkan. Cache bukan pengganti database server atau jaminan mode offline.

Kedua opsi tidak aktif sebelum dipilih. Menolak penyimpanan opsional tidak menghalangi login, pemuatan data dari server atau cache sementara di memori. Pada perangkat bersama, sebaiknya jangan menyimpan agenda secara persisten.

Mengubah pilihan

Pada pemberitahuan awal, pilih Hanya yang wajib, Izinkan opsional, atau Pengaturan cookie untuk mengatur kedua kategori secara terpisah. Buka lagi pengaturan dari halaman ini, footer Welcome atau bagian Privasi di perangkat pada Pengaturan akun. Tidak perlu login untuk mengubah pilihan.

Pengaturan cookie

Pilihan berlaku untuk browser/domain yang sama, termasuk saat berganti akun, bukan otomatis ke perangkat lain. Pilihan disimpan di browser, bukan sebagai rekaman persetujuan di server atau persetujuan terhadap Ketentuan Layanan.

Menarik izin menghapus cookie tema atau membersihkan cache agenda yang dikelola aplikasi; tidak menghapus agenda dan catatan pada server. Tema yang sedang tampil dapat tetap dipakai di memori sampai halaman dimuat ulang. Keluar akun membersihkan cache data akun, tetapi tidak menghapus cookie pilihan dan preferensi yang masih diizinkan.

Jika browser memblokir cookie pilihan, aplikasi menampilkan kegagalan penyimpanan. Tidak ada izin opsional yang dianggap tersimpan hanya karena tombol diklik. Menghapus data situs melalui browser menghapus pilihan lokal sehingga pemberitahuan dapat muncul kembali. Pilihan ini tidak memengaruhi cookie Google di situs Google.

Pelacakan dan penyedia

Aplikasi tidak mengaktifkan cookie iklan, analytics atau integrasi pemasaran. Netlify, FastAPI Cloud dan Google tetap dapat memproses metadata teknis untuk mengirim halaman, login dan keamanan layanan mereka. Pengaturan browser dan kebijakan penyedia juga berlaku; dokumen ini bukan klaim bahwa seluruh infrastruktur internet tidak memproses metadata.

Penanganan data akun dan hak pengguna dijelaskan pada Kebijakan Privasi. Rincian penyimpanan akan diperbarui jika fitur atau penyedianya berubah, dengan pemberitahuan dan pilihan tambahan bila diperlukan.
