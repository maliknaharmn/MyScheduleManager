# Public sign-in assets

- `public/previews/home-light.png` and `home-dark.png` are real captures of this application's Home, rendered with isolated synthetic API responses. Names, dates, note/checklist content and agendas are illustrative, not real account data. The sign-in page labels them accordingly. Regenerate from the current interface when its layout changes.
- Responsive 720/1200px AVIF copies are used when supported, with PNG fallback. The matching preload uses the same theme, srcset and sizes. `public/icons/brand-80.png` is a resized copy of the existing 192px icon for 40px UI slots, not a new logo.
- `public/icons/google-g.png` is resized from Google's published sign-in asset at https://developers.google.com/identity/images/g-logo.png. Google owns the mark; its branding guidelines apply: https://developers.google.com/identity/branding-guidelines. No independent artwork or new license is claimed.
- The existing MySchedule logo and icon masters are preserved; their separate source README remains authoritative.
